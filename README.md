# python-banking-
This is a simple banking system built in Python that runs in the terminal. It allows users to:  🆕 Create accounts 🔑 Log in with ID &amp; password 💰 Deposit, withdraw, and transfer money ⚠️ Handle overdrafts and inactive accounts 💾 Save and load data from a CSV file The project demonstrates object-oriented programming (OOP), file handling, and CLI.
